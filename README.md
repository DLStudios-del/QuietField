## 📥 Importing Your Own Audio

QuietField supports importing common audio formats including MP3, WAV, and FLAC files.

### How to Import:

1. Click the **Import** button in the toolbar
2. Browse to your audio file location
3. Select the file and click **Open**
4. Your imported sound will appear in a new "My Sounds" category
5. Mix it with built-in sounds just like any other sound

### Tips for Imported Audio:
- Use files with consistent volume levels
- Longer recordings work better for ambient purposes
- Stereo files provide a more immersive experience
